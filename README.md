# 🧮 Calculadora

Uma calculadora simples desenvolvida com HTML, CSS e JavaScript puro, criada como projeto prático após a conclusão dos cursos **JavaScript Essentials 1 e 2** da [Cisco Networking Academy](https://www.netacad.com/).

## 📖 Sobre o Projeto

Este projeto nasceu da vontade de colocar em prática os conhecimentos adquiridos nos cursos de JavaScript da Cisco, com foco especial na **manipulação do DOM**. O objetivo foi construir uma calculadora funcional do zero, sem frameworks ou bibliotecas externas.

## ✨ Funcionalidades

- Operações básicas: adição (`+`), subtração (`−`), multiplicação (`×`) e divisão (`÷`)
- Cálculo de porcentagem (`%`)
- Inversão de sinal (`+/−`)
- Suporte a números decimais (`.`)
- Limpeza completa do visor (`AC`)
- Exibição da expressão atual e do valor em tempo real

## 🗂️ Estrutura do Projeto

```
calculadora/
├── index.html   # Estrutura HTML da calculadora
├── style.css    # Estilização da interface
└── main.js      # Lógica e manipulação do DOM
```

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| HTML5 | Estrutura da página e botões |
| CSS3 | Estilização e layout da calculadora |
| JavaScript (Vanilla) | Lógica de cálculo e manipulação do DOM |

## 🚀 Como Usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/dioni-447/calculadora.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd calculadora
   ```
3. Abra o arquivo `index.html` no seu navegador.

Não é necessário instalar nenhuma dependência — o projeto roda diretamente no navegador.

## 🎓 Contexto de Aprendizado

Este projeto foi desenvolvido como exercício após concluir os cursos:

- **JavaScript Essentials 1** — Cisco Networking Academy
- **JavaScript Essentials 2** — Cisco Networking Academy
